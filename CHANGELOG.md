# Changelog

## 0.1.0

- Independent, typed parser for the models.dev `api.json` provider catalog.
- Exact JSON-number prices, tiered costs, typed capabilities, dates and limits.
- Bounded validation, extension preservation and deterministic filtered search.
- Optional rustls-only client with bounded gzip, conditional refresh and sanitized errors.
- Offline fixtures, mock HTTP contracts, examples and package-validation CI.
